## Переключение и откат в рабочем браузере

1. Остановить мониторинг и дождаться завершения текущей операции.
2. В той же вкладке заменить только URL API тестовым адресом и сохранить.
   Ключ и сопоставления ИНН/сертификатов не менять.
3. Запустить мониторинг; проверить новые записи подписи и ошибки.
4. При ошибке остановить мониторинг, дождаться завершения операции,
   вернуть прежний URL Gateway, сохранить и запустить мониторинг.

Не запускать второй экземпляр в другом браузере/origin: координация вкладок
действует только внутри одного origin/раздела хранилища.
Смена URL не отменяет подписи и удаления сообщений. Не считать сообщение
«ПОДПИСАНО И ВЫГРУЖЕНО» доказательством успешного DeleteMessage: оно пишется раньше.
Текущий SignJS также удаляет сообщение при скачивании с HTTP 403/404;
при таких ошибках проверку необходимо остановить.
