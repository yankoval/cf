# MAX messenger notifier

Yandex Cloud Function получает событие загрузки отчёта оборудования из
Object Storage и отправляет обратную связь в MAX.

## Поддерживаемые отчёты

### v1

Короба читаются из корневого `readyBox`. Функция отправляет одно сообщение со
сводкой и информационной PNG-карточкой. Задание оборудования дополнительно не
запрашивается.

### v2

Короба читаются из всех `readyPallet[].readyBox[]`. Функция:

1. проверяет `schemaVersion: 2`, закрытие паллетов и формат SSCC;
2. загружает `equipment-tasks/<report-id>.json`;
3. проверяет, что каждый SSCC паллета заранее назначен в
   `task.palletNumbers`;
4. отправляет сводку по отчёту;
5. отправляет отдельный печатный PNG-ярлык для каждого паллета.

Ярлык содержит полный SSCC и штрихкод GS1-128 с AI `00`. Для генерации
используется `python-barcode` и уже включённый в функцию Pillow.

Страховые SSCC, назначенные заданию, но не использованные в отчёте, в MAX не
отправляются.

## Переменные окружения

| Переменная | Обязательная | Значение |
|---|---:|---|
| `MAX_BOT_TOKEN` | да | Токен бота MAX. |
| `MAX_CHAT_ID` | да | Чат для уведомлений. |
| `AWS_ACCESS_KEY_ID` | да | Ключ Object Storage. |
| `AWS_SECRET_ACCESS_KEY` | да | Секрет Object Storage. |
| `S3_ENDPOINT` | нет | По умолчанию `https://storage.yandexcloud.net`. |
| `EQUIPMENT_TASKS_BUCKET` | нет | Бакет заданий. По умолчанию используется бакет отчёта. |
| `EQUIPMENT_TASKS_PREFIX` | нет | По умолчанию `equipment-tasks`. |

Роль функции должна иметь право чтения как отчёта, вызвавшего событие, так и
соответствующего задания оборудования.

## Формат уведомлений v2

Для отчёта с двумя паллетами отправляется три сообщения:

1. общая сводка;
2. ярлык паллета 1/2;
3. ярлык паллета 2/2.

Повторный результат контрольного сканирования не хранится этой функцией.
Сканирование должно обрабатываться отдельной принимающей процедурой, которая
сравнивает код с заданием и отчётом и сохраняет идемпотентное состояние
подтверждения.

## Локальная проверка

```bash
python -m unittest discover -s max-messenger-notifier -p 'test_*.py' -v
```
